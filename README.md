# MCPEnabled-Agents
MCP Enabled Agents
MCP implementation - MCP Enabled server to client N8N-GSheet to GMail workflow
Secure Bridge: The MCP Client node acts as an HTTP-based communication link between the AI Agent and the n8n MCP server using OAuth2 authentication.
Dynamic Data Retrieval: When prompted, the AI Agent queries the server to pull real-time execution metadata, workflow statuses, and timestamps from MCP-enabled workflows.
